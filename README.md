# SMEZI

O site institucional da SMEZI fica nas branches `v4` e `gh-pages`. Este trabalho é o Brand Studio.

O assistente de marca, o Brand Brain e o Brand Guide estão descritos em [BRAND-STUDIO.md](BRAND-STUDIO.md). Para a geração com modelo, a Vercel precisa de `OPENAI_API_KEY` (opcionais: `OPENAI_MODEL`, `OPENAI_BASE_URL`). Sem a chave, o estúdio segue com um entendimento local.
